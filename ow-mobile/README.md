# OW 트래커 (안드로이드 앱)

폰 가로 화면용 궁극기/쿨타임 트래커입니다. 음성이 기본이고 터치로도 쓸 수 있어요.

## APK 만드는 법 (GitHub, 5~10분)
1. github.com 가입 후 오른쪽 위 + → New repository (이름 예: ow-tracker) → Create
2. 이 폴더 안의 **모든 파일과 폴더(.github 포함)** 를 저장소에 업로드 (Add file → Upload files, 폴더째 끌어다 놓기)
3. 위 Actions 탭 → 왼쪽 "Build APK" → Run workflow → 초록색 체크가 뜰 때까지 5~8분 대기
4. 완료된 실행을 눌러 맨 아래 Artifacts 의 **ow-tracker-apk** 다운로드 (zip 안에 app-debug.apk)
5. 폰으로 apk 를 옮겨 설치 (설정에서 "출처를 알 수 없는 앱 설치" 허용 필요)

빌드가 빨간색으로 실패하면 실패한 단계의 로그 마지막 20줄을 복사해서 보내 주세요.

## 음성 명령 (PC 오버레이와 같아요)
- 추가 디바 트레 겐지 / 초기화
- 1번 e · 3번 쉬프트 · 5번 우클릭 (이 = e)
- 3번 궁극기 이천 오백
- 2번 교체 한조 · 겐지 교체 캐서디
- 영웅 이름으로도 가능: 겐지 e, 디바 궁극기 3000
- 헤더의 [상시/버튼]: 상시=계속 듣기, 버튼=[음성]을 누를 때 한 번 듣기

영웅/별명/쿨타임 데이터는 www/data.js, www/index.html 안에 있어요 (앱에서도 길게 눌러 수정 가능).
